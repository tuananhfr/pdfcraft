# ERPCons changes

This branch (`erpcons`) is the ERPCons Văn phòng fork of [PdfCraft](https://github.com/storytold/pdfcraft), based on PdfCraft by the ArtCraft team, licensed MIT OR Apache-2.0 (see `LICENSE-MIT`, `LICENSE-APACHE`, `NOTICE`). Changes from upstream `main` (Apache-2.0 §4b):

- Removed the ArtCraft logos and marks (`docs/brand/` and their ATTRIBUTION entries) and every link to the ArtCraft Discord and getartcraft.com, as the ArtCraft brand terms require for forks: title-bar Discord button, home-screen community card, About dialog, Help menu entries, CLI and MCP server info, README. The README screenshot was regenerated without the mark.
- About now reads "ERPCons Văn phòng — dựa trên PdfCraft của nhóm ArtCraft. MIT OR Apache-2.0."; Help ▸ "PdfCraft on GitHub" and the releases page point at this fork.
- Help ▸ "Check for updates…" is not in the web build's menu.
- Dropped the translations of the removed strings.
- Web draft autosave for the ERPCons Văn phòng shell (`crates/ui-egui/src/drafts.rs`, `apps/pdfcraft-web/src/main.rs`): unsaved documents are handed to `window.erpDrafts` (format `pdf`, the working bytes) after 2.5 s idle / 30 s of continuous edits and when the page is hidden, removed once saved, undone to saved or closed, and drafts the shell restores reopen unsaved under their key. Off without `window.erpDrafts` and in `?host=parent` mode; the desktop recovery store is unchanged.
- Vietnamese interface (`crates/ui-egui/src/i18n/vi.tsv`, code `vi`, one plural form) and Vietnamese date names (`crates/engine/src/dates.rs`), translated clean-room with Office-style Vietnamese command names (feature names only). The web build opens in Vietnamese unless the user picked another language and remembers the choice in `localStorage` key `erpcons-ui-language`, which the other ERPCons editors share (`apps/pdfcraft-web/src/language.rs`).
- Office-style keys: F1 opens Help ▸ Keyboard shortcuts, F12 saves as (with Ctrl+Shift+S), Ctrl+Y redoes (with Ctrl+Shift+Z), and plain `+` / `=` and `-` zoom in and out while no text field or text on the page is being typed in. The shortcuts dialog lists each command's alternate keys in its row and has a search box that filters by command name (in the UI language or English) or by key.
- Honest saving on the web (`crates/ui-egui/src/web_save.rs`): a document counts as saved only once the browser reports the file written, as it was written, so a cancelled save picker, a failed write or edits made while the picker is open leave it unsaved (and its office-shell draft kept). Save As uses the browser's save picker (Chrome, Edge), suggesting the current name and adopting the name picked for the tab, the window title and the next Save, which writes to that file again without asking; browsers without the picker (Firefox, Safari) ask for the file name in an in-app prompt (`.pdf` kept) before downloading. Save on a document never saved in the session behaves as Save As.
- Signed files keep their signatures (spec OF-14; `crates/engine/src/certification.rs`, `crates/ui-egui/src/cert_guard.rs`, `crates/sign/src/mdp.rs`): before Save or Save As, the unsaved edits are classified against the file as last saved in the validator's DocMDP words; edits a certification does not permit, or that change a field a signature locks (FieldMDP `/Reference` or the field's `/Lock`), hold the save in a dialog naming the signer and date with only "Save a copy…" and "Cancel", and a copy is never written over the signed original (`doc_save` refuses it too). A no-changes (P=1) certification shows a bar, refuses editing tools, edits and signing as they are used, and keeps viewing, printing, copying and Save As. Approval signatures without a lock never block.
- `deny.toml` ignores the RustSec advisories published in October 2026 that do not reach PdfCraft, each with its reason: rustls 0.23.45 (RUSTSEC-2026-0346…0349; the update check is the only TLS client) and the unmaintained zbus 5 helper crates (RUSTSEC-2026-0370…0372; Linux D-Bus only).
